# Ring

在 macOS 上连按同一侧 Option 键两次，按住第二次，鼠标位置会弹出一个圆环。移动鼠标选方向，松开就启动那个位置上的应用。

免费使用，开源，采用 MIT 许可。

![Ring 的圆环启动器](https://github.com/1993yihuan/Ring/releases/download/v0.1.3/preview.png)

官网：https://1993yihuan.github.io/Ring/

## 能做什么

- 在鼠标位置打开 8 个位置的圆环，位置数可以调成 3 到 8 个。顶部是第 1 位，顺时针排到最后一位。
- 按住第二次 Option 时移动鼠标选方向，松开就启动。选中的位置会高亮，环心显示它的名字。
- 指向空位时环心显示「空位」，松开什么都不会启动。
- 也可以从菜单栏手动打开圆环，用鼠标点选。
- 取消随时可用。按 Esc 取消，松开时停在环心、图标之间的空隙或空位上也会取消。
- 每个位置放一个应用，可以换一个、清空、拖动排序。改动立即保存。
- 没有动画。圆环出现时就已经画完整，不会先闪一下再变。
- 只占菜单栏，不占 Dock。

## 下载与安装

安装包在 [GitHub Releases](https://github.com/1993yihuan/Ring/releases) 上免费下载，源码公开在同一个仓库，代码采用 [MIT 许可](LICENSE)。

### 选对安装包

点苹果菜单，选「关于本机」，看芯片或处理器：

- 芯片写 Apple M1、M2、M3 或更新型号：下载文件名里带 `apple-silicon` 的那个。
- 处理器写 Intel：下载文件名里带 `intel` 的那个。

选提供 DMG 附件的较新版本，文件名形如 `Ring-<版本>-apple-silicon.dmg` 和 `Ring-<版本>-intel.dmg`，按上面的芯片说明挑一个。系统要求 macOS 13 或更高。

### 安装

1. 双击下载的 DMG，打开磁盘映像。卷里就是 Ring.app。
2. 把 Ring.app 拖到「应用程序」里。放桌面、下载或别的位置也可以。
3. 在访达边栏推出这个磁盘映像。
4. 第一次打开时，系统可能提示无法验证开发者。任选一种方式放行：
   - 打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」，再确认一次。
   - 在访达里右键 Ring.app（或按住 Control 点按），选「打开」，然后在对话框里确认。

Ring 的槽位配置存在个人文件夹的 `Library/Application Support/Ring` 里，和 Ring.app 放在哪无关，移动或重新安装 App 都不会丢配置。只有从源码构建的 Demo 例外，它把数据留在自己的工程目录里。

### 第一次运行

1. 打开「应用程序」，双击 Ring。菜单栏出现一个虚线圆图标，Ring 没有 Dock 图标，退出也在菜单栏里。
2. 菜单栏 → 请求输入监控权限。
3. 打开「系统设置 → 隐私与安全性 → 输入监控」，勾选 Ring。系统要求重新打开时，从菜单栏退出 Ring 再打开一次。
4. 再看菜单栏里的第一项。监听正常时它写「手动打开环形（布局验证）」，监听没起来时写「手动打开环形（监听不可用）」，可以点「重试全局监听」重试。

放行开发者和授予输入监控是两项独立的授权。只做了第一步，连按 Option 不会有反应。还没授权时也能用菜单栏 → 手动打开环形 看看布局，点一下就能启动应用。

## 添加自己的应用

1. 菜单栏 → 设置…，也可以按 ⌘, 打开。
2. 左边是圆环预览，右边是槽位列表，编号和圆环一致。
3. 空的位置点「添加…」选一个 .app。已经有应用的位置右边有两个图标按钮：左右箭头换一个应用，垃圾桶清空这一位。清空后空位保留，编号不变。
4. 拖动右侧的行可以调整顺序。减少「可见位置数」只会隐藏后面的位置，调大就回来。
5. 改动立即保存。窗口底部有「保存」，快捷键 ⌘S，可以再写一次。写不进去时会显示红色错误，旁边的「打开配置目录」能在访达里定位配置文件。

## 使用

### 连按 Option 打开

1. 快速按一下同一侧 Option，再按一下并保持按住。两次必须是同一侧，左、右不能混用。
2. 圆环在鼠标位置出现。移动鼠标，指向的位置会高亮，环心显示它的名字。第二次可以一直按着，按多久都行。
3. 松开 Option，启动高亮位置的应用。松开时看鼠标的方向，移到另一块屏幕也算。
4. 取消：按 Esc。松开时停在环心、图标之间的空隙或空位上也是取消，按住期间按一下鼠标键也会取消。

较早的安装包不是这套操作，它是连按两次 Option 后点一下图标启动。

### 从菜单栏打开

1. 菜单栏 → 手动打开环形。
2. 移动鼠标，点一下要启动的图标。
3. 点环心、空隙或空位取消。

## 常见问题

**连按 Option 没有反应。** 先看菜单栏第一项是「布局验证」还是「监听不可用」。是后者就点「重试全局监听」，再到「系统设置 → 隐私与安全性 → 输入监控」确认 Ring 已勾选。两次按键要在同一侧，按得太慢不会被当成一次连按。

**第一次打开被系统拦下。** 打开「系统设置 → 隐私与安全性」，点「仍要打开」。或者在访达里右键 Ring.app 选「打开」。放行后通常可以直接打开，系统更新或移动过 App 之后可能再次提示。

**环心有时没有名字。** 名字只在选中某个位置时显示。指向空位显示「空位」，什么都不显示说明没有选中任何位置。

**配置存在哪里。** 文件是 `~/Library/Application Support/Ring/configuration.json`。设置窗口底部的「打开配置目录」可以直接在访达打开这个文件夹。

**怎么退出和卸载。** 菜单栏 → 退出 Ring。把 Ring.app 拖到废纸篓。想清掉配置时，再删除 `~/Library/Application Support/Ring` 文件夹，那里只有 Ring 自己的设置。

## 已知限制

- 签名是 ad-hoc，没有 Developer ID，也没有公证。第一次打开需要自己放行。
- 安装包按架构分别打包。Apple Silicon 包在打包后核对了可执行文件的架构，但没有在 M 系列机器上实际运行过。
- 0.1.3 及更早的安装包把配置写在 Ring.app 所在文件夹的上一级 data 目录。新版只读 `~/Library/Application Support/Ring`，不会自动搬动旧文件。
- 多显示器、缩放、睡眠唤醒等场景还没有逐项实测。
