# Ring

在 macOS 上连按同一侧 Option 键两次，按住第二次，鼠标位置会弹出一个圆环。移动鼠标选方向，松开就启动那个位置上的应用。

免费使用，开源，采用 MIT 许可。

![Ring 的圆环启动器](https://github.com/1993yihuan/Ring/releases/download/v0.1.3/preview.png)

官网：https://1993yihuan.github.io/Ring/

## 能做什么

- 在鼠标位置打开 8 个位置的圆环，位置数可以调成 3 到 8 个。顶部是第 1 位，顺时针排到最后一位。
- 按住第二次 Option 时移动鼠标选方向，松开就启动。选中应用时，该位置高亮，环心留空。
- 指向空位时环心显示「空位」，松开什么都不会启动。
- 菜单栏图标左键直接打开设置，右键弹出「设置…」和「退出 Ring」。
- 取消随时可用。按 Esc 取消，松开时停在环心、图标之间的空隙或空位上也会取消。
- 每个位置放一个应用，可以换一个、清空、拖动排序。改动立即保存。
- 设置窗口左侧包含环形设置、触发与手势、通用设置和关于。触发方式可选双击 Option、双击 Command 或自定义组合键；都不需要输入监控或辅助功能授权。
- 关于页显示当前版本。手动检查 GitHub 正式更新，下载后先校验官方摘要和包内容，再替换当前 Ring；安装失败会自动回滚。Ring 没有 Developer ID 签名，首次打开可能需要系统手动放行。
- 圆环从 12 点方向顺时针扫显出来（默认 0.14 秒，可在设置里改成 0 到 2000 之间的毫秒数，0 表示立即显示）：材质、投影、图标和空位随扫过的边界逐步揭开，图标的位置、大小和方向始终不动，被边界切到的图标就地慢慢露出；环心名称一直完整显示。取消或启动后整幅淡出（0.06 秒）。高亮换到另一个位置是 0.05 秒的渐变，环心名称立刻更新。
- 系统开启「减弱动态效果」时没有这些过渡：显示、切换、消失都立即完成。
- 只占菜单栏，不占 Dock。

## 下载与安装

安装包在 [GitHub Releases](https://github.com/1993yihuan/Ring/releases) 上免费下载，源码公开在同一个仓库，代码采用 [MIT 许可](LICENSE)。

### 选对安装包

点苹果菜单，选「关于本机」，看芯片或处理器：

- 芯片写 Apple M1、M2、M3 或更新型号：下载文件名里带 `apple-silicon` 的那个。
- 处理器写 Intel：下载文件名里带 `intel` 的那个。

选提供 DMG 附件的较新版本，文件名形如 `Ring-<版本>-apple-silicon.dmg` 和 `Ring-<版本>-intel.dmg`，按上面的芯片说明挑一个。系统要求 macOS 13 或更高。

### 安装

1. 双击下载的 DMG，打开磁盘映像。卷里就是 Ring.app。
2. 把 Ring.app 拖到「应用程序」里。放桌面、下载或别的位置也可以。
3. 在访达边栏推出这个磁盘映像。
4. 第一次打开时，系统可能提示无法验证开发者。任选一种方式放行：
   - 打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」，再确认一次。
   - 在访达里右键 Ring.app（或按住 Control 点按），选「打开」，然后在对话框里确认。

Ring 的槽位配置存在个人文件夹的 `Library/Application Support/Ring` 里，和 Ring.app 放在哪无关，移动或重新安装 App 都不会丢配置。只有从源码构建的 Demo 例外，它把数据留在自己的工程目录里。

### 第一次运行

1. 在「应用程序」打开 Ring，菜单栏出现虚线圆图标；Ring 不占 Dock。
2. 直接连按同一侧 Option 两次，第二次按住可移动鼠标选择，松开执行。不需要「输入监控」权限。想换触发方式，去设置 →「触发与手势」。
3. 如果没有反应，先确认两次按键来自同一侧。仍不行就退出 Ring 再重新打开。

首次运行遇到 Gatekeeper 拦截时仍需要手动放行；这与键盘监听无关。

## 添加自己的应用

1. 菜单栏 → 设置…，也可以按 ⌘, 打开。
2. 左边是圆环预览，右边是槽位列表，编号和圆环一致。
3. 空的位置点「添加…」选一个 .app。已经有应用的位置右边有两个图标按钮：左右箭头换一个应用，垃圾桶清空这一位。清空后空位保留，编号不变。
4. 拖动右侧的行可以调整顺序。减少「可见位置数」只会隐藏后面的位置，调大就回来。
5. 改动立即保存。窗口底部有「保存」，快捷键 ⌘S，可以再写一次。写不进去时会显示红色错误，旁边的「打开配置目录」能在访达里定位配置文件。

## 使用

### 连按 Option 打开

1. 快速按一下同一侧 Option，再按一下并保持按住。两次必须是同一侧，左、右不能混用。
2. 圆环在鼠标位置出现。移动鼠标选中应用，该位置会高亮，环心留空。第二次可以一直按住 Option。
3. 松开 Option，启动高亮位置的应用。松开时看鼠标的方向，移到另一块屏幕也算。
4. 取消：按 Esc。松开时停在环心、图标之间的空隙或空位上也是取消，按住期间按一下鼠标键也会取消。

较早的安装包不是这套操作，它是连按两次 Option 后点一下图标启动。

### 触发与手势

设置 →「触发与手势」里单选一种启动方式，选中立即生效，存在配置目录的 trigger.json 里，重启 Ring 后继续使用。

1. **双击 Option**（默认）：上面那一节的操作。
2. **双击 Command**：同样连按同一侧 Command，第二次按住时移动鼠标选择，松开启动。按住 Command 时系统可能显示「键入以使用 Siri」提示，这是系统行为，Ring 不改变它。
3. **自定义组合键**：点「录制」，在这个设置窗口里直接按下组合键，采纳后可以马上按住试一次。组合键是**一个修饰键加一个普通键**，修饰键可以是 Command、Control、Option 或 Shift 中的一个；两个修饰键、只有修饰键、或者只按普通键都会被拒绝。⌘Space、⌃Space、⌘Tab 这类系统占用的组合会被拒绝。录制时按 Esc 取消，切换页面或窗口失去焦点时录制自动结束并恢复原触发。

   组合键注册成功后，这个组合在本机就归 Ring 使用，其他应用里的同一组合可能不再触发（这是系统级注册的语义，不是 Ring 主动改写别人的设置）。如果系统拒绝注册，Ring 会显示系统返回的原因，并保留原来能用的触发。Ring 只能发现同样通过系统注册的重复组合，无法列出所有应用自己的快捷键。

自定义组合键的用法和双击 Option 一样：**同时按住这两个键**，圆环在鼠标位置出现；移动鼠标选择；**先松开任意一个键**，就启动松开时指着的那一个应用，没选中就只是关闭。同一次按住只启动一次，按键的自动重复不会再打开。

用 Shift 或 Option 加字母时注意两件事：Shift 加字母在别的应用里本来是大写输入，Option 加字母可能产生特殊字符或参与输入法组合，所以这个组合被 Ring 占用后，那些输入在那台机器上可能不再照原样出现。Ring 只保证按系统的注册规则占用了这个组合，不能保证它在每个应用、每种输入法下都被送达。

旧版本保存的多修饰键组合（例如 ⌘⌥K）在新版只支持单修饰键后无法继续使用：启动时会临时改用双击 Option，并提示你重新录制。原来的 trigger.json 不会被改写，只有你在设置里重新录制并保存后才会替换。

改动如果保存失败，或者系统不接受这个组合，Ring 会保留原来能用的触发并显示原因。如果保存的组合键在启动时注册不上（比如被别的应用占用），这一次会临时使用双击 Option，「触发与手势」页会写明原因，保存的选择保持不变。

Ring 只能发现同样通过 Carbon 注册的重复组合（系统会直接拒绝）；对用其他方式监听键盘的应用，以及系统自己占用的组合（如 ⌘Space），Ring 靠自己的保留列表拒绝，不能保证查出全部冲突。

## 常见问题

**连按 Option 没有反应。** 两次按键必须来自同一侧 Option，按得太慢不会被识别。可以退出 Ring 再重新打开。轮询方案已在 Intel Mac 上验证，其他 Mac 和 macOS 版本尚需逐项验证。

**第一次打开被系统拦下。** 打开「系统设置 → 隐私与安全性」，点「仍要打开」。或者在访达里右键 Ring.app 选「打开」。放行后通常可以直接打开，系统更新或移动过 App 之后可能再次提示。

**环心什么都没有。** 选中应用时环心留空。指向空位时，环心显示「空位」。

**换了触发方式后没反应。** 双击必须来自同一侧、同一修饰键，按得太慢不会被识别。自定义组合键要**同时按住**一个修饰键（Command、Control、Option 或 Shift）加一个普通键，先松开任意一个键才启动；系统占用的组合不能用，旧版的多修饰键组合需要重新录制。「触发与手势」页会显示当前生效的触发或失败原因；最保险是「恢复默认（双击 Option）」，再到启动方式里重选一次。

**配置存在哪里。** 文件是 `~/Library/Application Support/Ring/configuration.json`。设置窗口底部的「打开配置目录」可以直接在访达打开这个文件夹。

**怎么退出和卸载。** 菜单栏 → 退出 Ring。把 Ring.app 拖到废纸篓。想清掉配置时，再删除 `~/Library/Application Support/Ring` 文件夹，那里只有 Ring 自己的设置。

## 已知限制

- 签名为 ad-hoc，没有 Developer ID 与公证。首次打开或更新后，Gatekeeper 可能要求手动放行。Option 轮询不需要输入监控权限。
- 安装包按架构分别打包。Apple Silicon 包在打包后核对了可执行文件的架构，但没有在 M 系列机器上实际运行过。
- 0.1.3 及更早的安装包把配置写在 Ring.app 所在文件夹的上一级 data 目录。新版只读 `~/Library/Application Support/Ring`，不会自动搬动旧文件。
- 多显示器、缩放、睡眠唤醒等场景还没有逐项实测。
