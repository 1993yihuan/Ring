## 新增与改进

- 全新浅色设置界面与窗口布局：采用浅色卡片视觉与更紧凑的默认窗口，左侧导航栏支持整行点击与手指光标，并修复首次打开时侧栏行距异常。
- 圆环预览选中与悬停体验升级：打开设置时默认不选中槽位、中央盘面留空，点击已填槽位才在中央显示应用信息及「更换」「移除」；鼠标移入已填槽位图标放大 1.5 倍，移出、拖动或播放「预览动画」时立即恢复。
- 展开时长与可见位置数调节更顺手：展开时长滑块按 50 ms 步进调节（0–2000 ms，0 ms 为立即显示）并与输入框实时同步；调小可见位置数仍保留隐藏槽位配置，调大即可恢复。
- 统一「触发与手势」「通用设置」「关于」页及快速应用选择器的浅色卡片样式，保持一致的布局、图标显示与键盘检索体验。

## What's New & Improved

- Redesigned the Settings window with a light card-based layout and a more compact default size; the left sidebar now supports full-row clicking with a pointing-hand cursor and fixes initial row-spacing misalignment on first open.
- Separated slot selection from hover magnification in the ring preview: the center hub stays blank until you click an occupied slot to show its name with Replace and Remove actions; hovering an occupied icon enlarges it to 1.5x and resets immediately on exit, drag, or Preview Animation.
- Refined the visible slot count and entrance duration controls: the duration slider snaps in 50 ms steps from 0 to 2000 ms (0 ms opens immediately) in sync with the text field, and lowering the slot count preserves hidden slots so raising it brings them back.
- Unified the light appearance across Triggers & Gestures, General, About, and the quick app picker while keeping icon rendering and keyboard search consistent.
