## 新增与改进

- 启动台唤出与收起动画统一调整为「轻盈开合」（居中缩放淡入与缩小淡出，替代原有的顺时针环形展开），支持按 0–2000 ms 调节展开时长（0 ms 为立即显示）并遵循系统「减弱动态效果」；动画播放期间仍可直接选择或取消、点击即刻启动应用无需等待收起，收起过程中也可再次唤出。
- 设置页「预览动画」与实际启动台共用同一套「轻盈开合」开合动画与时长，并改进预览的向下投影、底部提示浮层展示与播放中图层稳定性；修改展开时长后无需回车即可直接点击「预览动画」即时生效。

## What's New & Improved

- Unified the launcher ring open and close animation to Gentle Scale (centered scale-and-fade entrance and exit, replacing the previous clockwise sweep reveal), honoring the 0–2000 ms entrance duration setting (0 ms opens immediately) and macOS Reduce Motion; you can still select or cancel mid-animation, launch apps immediately without waiting for the close fade, and reopen the ring while it is closing.
- Aligned Settings "Preview Animation" with the live launcher's Gentle Scale animation and timing, while improving the preview's downward shadow, bottom toast visibility, and layer stability during playback; typing a new entrance duration takes effect immediately when clicking Preview Animation without pressing Return first.
