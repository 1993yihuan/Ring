## 新增与改进

- 槽位在应用之外新增三类动作：打开网址、打开文件或文件夹、锁定屏幕，可在「应用｜网址｜快捷功能」三页签选择器中添加，拖拽换位与隐藏尾槽的行为保持不变。
- 新增网址槽位：可直接输入网址或裸域名（自动补全 https://），也支持常见的应用 Deep Link；仅在设置页后台抓取网页标题与站点图标并缓存到本地，唤出圆环时不发起任何网络请求，抓取失败时用首字母圆角图标兜底，并可手动重新获取。
- 新增文件与文件夹槽位：通过访达选择文件或目录并使用系统图标；选到 .app 时会自动归类为应用槽位。
- 新增「锁定屏幕」快捷功能：松手即锁屏，不需要辅助功能或输入监控等额外系统权限，调用异常时回退为关闭显示器。
- 通用设置新增「悬停时在环心显示名称」（默认开启）：开启后应用、网址、文件、锁屏四类槽位悬停时统一在环心显示名称，关闭后统一留空，空位仍显示「空位」。
- 编辑已有网址时，换成另一个网址或改成非法地址会立即清除旧站点图标，保存时也不会把上一个站点的图标写给新网址。
- 升级兼容：0.2.5 及更早版本的配置可以直接沿用，已有的应用槽位无需重新配置。

## What's New & Improved

- Slots now support three new action types besides apps: open a website, open a file or folder, and lock the screen. Add them from the three-tab picker (Apps | Websites | Quick Actions); drag-to-reorder and hidden trailing slots work as before.
- New website slots: enter a URL or a bare domain (https:// is filled in), or a common app deep link. The page title and site icon are fetched in the background only while you are in Settings and cached locally, so opening the ring makes no network request; when fetching fails you get a rounded letter icon instead, and you can fetch again manually.
- New file and folder slots: pick a file or directory in Finder and the system icon is used; picking a .app is filed as an app slot automatically.
- New Lock Screen quick action: release-to-lock with no extra system permission such as Accessibility or Input Monitoring, falling back to sleeping the display if the call fails.
- General settings adds "Show name in ring center on hover" (on by default): when on, app, website, file and lock screen slots all show their name in the ring center on hover; when off they all stay blank, and empty slots still show "Empty".
- Editing an existing website now clears the old site icon as soon as you switch to another URL or an invalid one, and saving never writes the previous site's icon to the new URL.
- Upgrade compatibility: configurations from 0.2.5 and earlier keep working, and existing app slots need no reconfiguration.
