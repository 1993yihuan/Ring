## 新增与改进

- 通用设置新增「触控板轻微震动反馈」开关（默认开启并自动保存，兼容旧版配置）：展开环形启动器并将指针移入新的已配置槽位时触发一次轻微触感反馈，不支持触感硬件的设备会静默降级。
- 设置页圆环预览悬停已配置槽位时显示手指光标；移出、清空槽位、调整可见位置数、切换页面、关闭窗口或拖拽结束后自动恢复默认光标。

## What's New & Improved

- Added a Trackpad Haptic Feedback toggle in General Settings (enabled by default and saved automatically, compatible with existing configurations): opening the ring launcher and moving the pointer into a newly hovered configured slot triggers a subtle tactile pulse, with silent fallback on Macs without Force Touch hardware.
- Showed a pointing-hand cursor when hovering over configured slots in the Settings ring preview, automatically restoring the default cursor when leaving a slot, clearing a slot, changing the visible slot count, switching tabs, closing the window, or finishing a drag.
