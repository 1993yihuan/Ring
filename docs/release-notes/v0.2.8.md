## 新增与改进

- 通用设置新增基于 macOS 原生登录项（`SMAppService`）的「开机自启动」，状态与系统实时同步，首次开启或需系统确认时可直接跳转「登录项与扩展」。
- 新增「前台应用再选时返回上一个应用」（默认开启，可在通用设置中关闭）：唤出圆环后悬停当前前台应用槽位会切换为返回箭头图标并在环心提示目标应用，松手直接切回上一个应用而不隐藏当前应用，无需额外系统权限。
- 全新改版 Ring 官网（暖纸精装多屏布局、可交互 3–8 槽位圆环演示与最新下载入口）并同步更新 README 使用说明。

## What's New & Improved

- Added "Launch at Login" in General settings backed by macOS native `SMAppService`, syncing live with system state and linking directly to "Login Items & Extensions" when confirmation is required.
- Added "Return to previous app when selecting the frontmost app" (enabled by default, toggleable in General settings): hovering the frontmost app slot switches it to a return arrow with the target app shown in the ring center, letting you switch back on release without hiding the current app or requiring extra permissions.
- Redesigned the Ring website with a multi-section warm-paper layout, interactive 3–8 slot ring demo, and updated download links, alongside an updated README guide.
