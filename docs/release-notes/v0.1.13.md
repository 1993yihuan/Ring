## 新增与改进

- 连按 Option 不再申请「输入监控」权限：Ring 改为自己定时读取 Option 键状态，键盘不进事件监听，系统不会再要求授权，也不需要重新勾选。
- 两次按键必须来自同一侧 Option。读数互相矛盾、左右两侧同时按下或中途换成另一侧时，这段手势直接作废，不会被当成一次连按；第二次按下仍可移动鼠标选择，松开执行。
- 设置窗口去掉「权限与安全」页，菜单栏去掉「请求输入监控权限」和「打开系统设置（输入监控）」，只保留「重试全局监听」。关于页同步说明：更新只来自 GitHub 正式版本，下载后按官方摘要校验；Ring 没有 Developer ID 签名，安装后 macOS 仍可能要求手动放行新安装的版本。
- 更新前先确认磁盘上的 Ring.app 就是正在运行的这一份：启动后被替换或重建过，会在下载前直接拒绝，并提示退出 Ring 后重新打开。真正替换前的最后一次检查也会核对这一点，不会装到中途变过的版本。
- 项目的构建脚本统一使用 ad-hoc 签名，不再通过 RING_LOCAL_SIGNING_IDENTITY 与 RING_LOCAL_SIGNING_CERT_SHA256 改用本机自签名证书；脚本之外的签名方式不在本次说明范围内。
- README 的首次运行、常见问题与已知限制按新方式重写：先确认两次按键同侧，再试「重试全局监听」。

## What's New & Improved

- A double tap of Option no longer asks for Input Monitoring: Ring reads the Option key state on a timer of its own, no keyboard goes through an event listener, and the system no longer asks for that permission or needs it re-ticked.
- Both presses must come from the same side of Option. Readings that disagree, both sides held at once, or a switch to the other side mid-gesture drop the whole gesture instead of becoming a double tap; the second press can still move the pointer to pick a slot, and the release launches.
- The settings window no longer has a "Permissions & Security" page, and the menu bar no longer has "Request Input Monitoring Permission" or "Open System Settings (Input Monitoring)"; only "Retry Global Listener" stays. The About page now says the same: updates come only from official GitHub releases and are checked against the published digest, Ring has no Developer ID signature, and macOS may still ask you to allow a newly installed version.
- Before an update, Ring confirms that the Ring.app on disk is the copy it is running from. If that copy was replaced or rebuilt since launch, the update is refused before the download and Ring asks you to quit and reopen it. The last check before replacing compares the same files again, so a version that changed mid-install is never swapped in.
- The project's build script always ad-hoc signs the bundle now, and no longer reads RING_LOCAL_SIGNING_IDENTITY or RING_LOCAL_SIGNING_CERT_SHA256 to sign with a local self-signed certificate. Signing a build by hand outside the script is out of this note's scope.
- The README covers the new setup in First Run, FAQ and Known Limits: check that both presses use the same side first, then try "Retry Global Listener".
