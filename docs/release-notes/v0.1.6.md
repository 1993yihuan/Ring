## 新增与改进

- 设置页的圆环预览改用与启动台同一套绘制代码和几何计算，看到的就是实际效果。
- 预览按可用区域等比缩放并居中，窗口大小和位置数变化都会自动适配。
- 改动位置后预览立即同步，不用关掉窗口再打开。
- 预览是静态画面，不播放动画，也不响应点击。

## What's New & Improved

- The settings ring preview now uses the same drawing code and geometry as the launcher, so it shows what you will actually get.
- The preview scales to fit its area and stays centred as the window size or the number of positions changes.
- Changing a position updates the preview at once, without closing and reopening the window.
- The preview is a still picture: it plays no animation and does not respond to clicks.
