## 新增与改进

- 用 Option 唤出圆环后，选中应用时中心只显示应用名。松开 Option 即可启动选中的应用。
- 左键点击菜单栏图标直接打开设置。已有设置窗口会移到前台，最小化时会还原。右键打开原有菜单。

## What's New & Improved

- When you select an app in the ring opened with Option, the centre shows only the app name. Release Option to launch the selected app.
- Left-click the menu bar icon to open Settings. Ring brings the existing Settings window to the front and restores it if minimised. Right-click to open the existing menu.
