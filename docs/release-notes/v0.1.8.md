## 新增与改进

- 关于页可以检查更新：只有点「检查更新」才访问 GitHub，只读正式发布，跳过草稿和预发布，也不接受比当前更低的版本。
- 有新版本时显示版本号和说明；点「更新」才开始下载，能看到进度，也能取消。
- 下载按 GitHub 公布的 SHA-256 摘要校验，再核对包标识、版本、架构和最低系统版本；摘要缺失或任意一项对不上都不会安装。
- 安装前把当前 Ring 备份到同一个文件夹，替换后重新打开；如果 Ring 还在运行、新版本起不来，或启动后 0.9 秒内就退出，会自动换回旧版本并说明原因。
- 当前是 Apple 芯片还是 Intel，按实际运行的那份程序判断，所以经 Rosetta 运行时安装的是 Intel 包。
- 权限与安全页新增输入监控卡，整张从环形设置页搬过来，按钮和判断逻辑没有改动。
- 触发与手势、通用设置两页仍是「待开发」。

## What's New & Improved

- The about page can check for updates: only clicking "Check for Updates" contacts GitHub, and it reads published releases only, skipping drafts and pre-releases and refusing anything older than the running version.
- When a newer version exists it shows the version and its notes, and only clicking "Update" starts the download, with progress you can watch and cancel.
- The download is checked against the SHA-256 digest GitHub publishes, then against the bundle identifier, version, architecture and minimum system version; a missing digest or any mismatch means no install.
- Before installing it backs the current Ring up to the same folder and reopens the new one; if Ring is still running, the new version will not start, or it exits within 0.9 seconds, the old version comes back with the reason.
- Whether this Mac is Apple silicon or Intel is read from the program actually running, so an app running under Rosetta installs the Intel build.
- The permissions and security page gains the Input Monitoring card, moved over from the ring page with its buttons and checks unchanged.
- Trigger and gestures and general remain "coming soon".
