## 新增与改进

- 修复应用启动期间无法再次唤出圆环的问题：选中应用 A 后，在圆环收起动画尚未结束或 A 仍在后台启动期间，再次使用原唤起手势（双击 Option、双击 Command 或自定义组合键）即可立即重新弹出圆环并启动应用 B，无需等待 A 打开完成。
- 优化异步启动回调处理：先前启动的延迟结果不会中断已重新弹出的圆环或后续启动操作。

## What's New & Improved

- Fixed an issue where the ring could not be summoned again while an app was still launching: after selecting app A, repeating your trigger gesture (double-tap Option, double-tap Command, or custom shortcut) during the closing animation or while A is still starting up now opens the ring immediately so you can launch app B without waiting for A to finish opening.
- Improved asynchronous launch completion handling so late results from an earlier launch no longer interfere with a reopened ring or a subsequent launch.
